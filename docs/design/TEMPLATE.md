## 現況問題

使用者遇到什麼困難、在哪一張截圖看得到。

## 決定

盡量具體，實作那邊才不用猜：
- 尺寸用 dp／sp，顏色與字級用 `UI-SPEC.md` 既有的 token 名稱（要新增 token 請寫出淺色與深色兩個值）
- 元件寫 Material 3 的元件名稱（例如 `FilterChip`、`ListItem`）
- 狀態要寫全：預設、選中、停用、載入中、空狀態、錯誤
- 深色模式與英文介面下有沒有不同

## 行為改變

Updates

What’s new in each version of Budget Book.

1.1.6

2026-11-12
  • One wallet can now hold several currencies: pick a currency when adding an entry; each currency is listed on its own, never converted or added together
  • Change a wallet’s default currency when managing wallets; the currency field for new wallets is now a searchable menu
  • After saving an entry, the home screen confirms it was saved
  • New Taiwan dollar amounts no longer show “.00”
  • The app is now called Budget Book

1.1.5

2026-11-02
  • Backups now update the same file instead of piling up
  • New: automatic backup at the end of each month (off by default)

1.1.4

2026-11-01
  • Backup reminders now come once at the end of each month, starting after 30 days of use, and skip months you’ve already backed up
  • Fixed the look of the budget progress bar

1.1.3

2026-10-29
  • The home list is grouped by day, with a divider when the year changes; the budget card now scrolls with the list
  • The date on the add screen is now a calendar button; while writing a note, categories shrink to one row
  • Better TalkBack support for deleting entries
  • Fixed a blank row appearing after swiping to delete or undoing

1.1.2

2026-10-27
  • Categories are shown in two rows, in the order you arranged them
  • Weekly subtotals now show income minus spending
  • The number pad hides while you write a note
  • The “Entertainment” category is renamed “Leisure”

1.1.1

2026-10-22
  • First test release: multiple wallets, weekly or total budgets, stats, backup and restore, dark mode, English and Chinese
  • Optional “Help improve the app” switch in Settings (off by default), and a way to support the developer
  • New app icon
